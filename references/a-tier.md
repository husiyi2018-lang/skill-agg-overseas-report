# A 档专章:多路交叉采样与汇聚

> 读此文件的时机:**步骤 2 判定为 A 档**时。B/C 档不读,走主路径单会话(或减路)即可。
> A 档 = 在投素材量大(通常 ≥5 万条)或报告要对客户演示 / 跨团队讲。

## 一、档位判定

| 档位 | 判定 | 采样 | 竞品对标 |
|---|---|---|---|
| A | 在投量大(≥5 万条)或对外演示 | ≤8 路并行交叉 | **必查**(独立会话实查) |
| B | 中小在投量 / 内部周报 | 减路(~4 路)或单会话融合 | 需求提及才查 |
| C | <100 条(小样本) | 单会话融合,自动限缩结论强度 | 不查 |

## 二、8 路拆分(每路独立会话,互不引用)

按 `references/intent-presets.md` 的「A档交叉采样模板」R1-R8 发起,各附通用要求块(全文中文 + 分档给数 + 素材附完整 ID)。chat_mode 与主产品同档(短剧=8)。`claw.py analyze` 会落到 `raw/data/result_L{n}_{tag}.md`(分析原文)与同名 `.json`(仅元数据)。

- R1 自身·窗口趋势与节奏
- R2 自身·素材结构与形态
- R3 自身·题材/方向骨架
- R4 自身·头部素材与爆款门槛
- R5 竞品·赛道格局(必查)
- R6 竞品·各对手打法(必查)
- R7 自身·话术资产(钩子排行 + 话术模板)
- R8 自身·人群锚点

**裁减顺序(耗时敏感时在 8 内砍)**:至少保 `竞品×1 + 自身素材×1 + 自身趋势×1`;优先省 人群/话术/自身头部 各 1。禁止砍到只剩单会话还声称"交叉验证过"。

## 三、并发与失败处理(实测 2026-09 DramaBox)

- **并发 ≤3,分批跑**:8 路同时 POST 触发网关 504(重路约 600s 被掐)。每批 2-3 路各自后台,批间等待。`claw.py analyze --conc 3` 已内置分批。
- **两类假结果**:
  1. HTTP 504(约 600s 返回)= 网关上游超时,非引擎结论 → 可重试。
  2. HTTP 200 但 body 极小(<1KB)且含「系统繁忙 / 请稍后 / 抱歉」= 引擎繁忙占位,**假成功** → 当失败,勿入库。
- **重试 = 新会话,不轮询**:504/繁忙没有可用 session_id;把同一 input 当新会话重发(天然独立样本,不破坏交叉验证)。`claw.py` 默认自动重试 1 次。
- **最多重试 1 次即降级**:同路 2 次失败即停,该路标「未跑成」,维度由相邻路覆盖,报告口径注明"R 路未跑成,由 XX 覆盖",禁止虚标。

## 四、汇聚:交叉验证 = 客观置信度

- 同一结论被 **≥2 路独立会话**提到 → 高置信(可作数据事实/素材共性);**仅 1 路**提到但自洽 → 「机会点 / 待验证」;跨路数字冲突 → **保留各自口径并注明**,禁止取平均或挑好数。
- 每条结论句保留来源路(`raw/data/result_L{n}_{tag}.md`),便于溯源。
- 报告侧:核心信号块按"绿=高置信 黄=机会点"排;证据分层表注明由几路支撑。

## 五、A 档增强叙事模块

1. **资产寿命三层 + 环比**:新增(短周期试错)/ 中段(放量主力)/ 常青(压舱石)各层素材量 + 占比 + 环比;折旧信号(常青层塌陷/头部全老素材续跑/新素材进榜门槛抬高)。落 `life` 或 `table`。
2. **竞品/赛道对标(独立实查)**:同赛道头部独立会话实查量级与打法;统一口径后对比,主产品位置放赛道里讲(量级第几、哪块最克制/最激进),再落差异化机会点。竞品素材 ID 同样须可溯源并标对象名。
3. **资产化颗粒**:话术框架模板(模板句/适用题材/前3秒动作/收口)、前3秒钩子排行(附代表素材)、人群锚点映射(标置信度)。落 `table`/`dirs`;查不到整维删除,不写 N/A。

## 六、A 档验收

- [ ] 路数 ≤8;裁减符合裁减顺序
- [ ] 并发按批 ≤3;504/繁忙当新会话至多重试 1 次
- [ ] 未跑成的路已标「未跑成」+ 相邻路覆盖 + 口径注明,未虚标
- [ ] 竞品/赛道为独立会话实查,非顺带提及
- [ ] 结论带置信度(≥2 路=高 / 1 路=机会点);跨路冲突保留口径未取平均
- [ ] 每条结论可溯源到某路 raw 文件
