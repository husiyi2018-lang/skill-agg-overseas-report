# 意图预设 —— 选哪套骨架

> **先判定意图，再动手。** 骨架不同，要取的数据维度、章节数、素材呈现方式全都不同。
> 判错了会导致「取了一堆用不上的数」或「写到一半发现缺数」。

## 判定表

| 用户说的话 | 预设 | 主题 |
|---|---|---|
| 「分析 XX 游戏的素材策略」「这款 SLG / 二次元 / 休闲游戏投放怎么样」 | [`game-strategy`](#game-strategy--策略中重度游戏) | `gold` |
| 「XX 短剧 App 的素材」「出海短剧投放分析」「ReelShort / DramaBox 那种」 | [`short-drama`](#short-drama--出海短剧-app) | `base` |
| 「XX 这个 App / 工具 / 金融产品的素材投放」 | [`app-tool`](#app-tool--工具金融生活服务-app) | `teal` |
| 「对比 XX 和 YY」「竞品在打什么素材」「我们和对手的差距」 | [`competitor`](#competitor--竞品对标专项) | 跟随主产品 |
| 「拆解这条素材」「这条广告为什么有效」 | [`single-creative`](#single-creative--单素材深拆) | 跟随主产品 |

**用户没明说时**：默认 `game-strategy`（结构最完整，删章节比加章节容易）。

## 素材量档位

**档位决定分析深度和取数轮次，不是报告长度。**

| 档位 | 触发（窗口内在投素材数） | 取数 | 素材呈现 | 典型耗时 |
|---|---|---|---|---|
| **A 档** | ≥ 50,000 | aggclaw ≤8 路独立采样交叉验证 + 会话素材清单全量 | 40–60 条内嵌视频 | 2–4 小时 |
| **B 档** | 1,000 – 50,000 | aggclaw 2–3 轮 + 清单聚合维度 | 20–40 条 | 1–2 小时 |
| **C 档** | < 1,000 | aggclaw 单会话 + 清单逐条核对 | 10–20 条，多以封面为主 | 30–60 分钟 |

> 量级判断依据：先让 aggclaw 报窗口内素材总数（或数去重后的会话素材清单），再定档。

**交叉验证规则（A 档必做）**：
- 同一问题**至少 2 路独立采样**（不同提示词角度问同一件事）
- ≥2 路结论一致 → **高置信度**，正文可断言
- 仅 1 路 → 标为**机会点**，措辞降级
- 两路采样口径冲突（差异 >20%）→ **严禁取平均**，正文用主口径 + 在「数据口径说明」注明分歧

## `game-strategy` —— 策略 / 中重度游戏

**主题**：`gold`　**骨架**：`assets/shell.html`（外壳槽位）+ `references/BLOCKS.md` 的
`结论摘要` / `chartgrid` / `stepper` / `tl` / `gal` / `flow` / `mmk` / `aud` 八类区块

### 章节骨架（9 章，一级导航 9 个）

| 章 | 标题 | 核心块 |
|---|---|---|
| 0 | 🧭 结论摘要 | `blockquote.lead` + 维度表（`tablewrap`，列用「维度/本产品/参照/含义」） |
| 1 | 🔥 外部环境 | `cardnote` 筛选说明 + `newsbtn` 资讯表 + `kgrid` 压力线 |
| 2 | ⚙️ 平台算法与推荐逻辑 | `blockquote` 为主，讲 Meta/TikTok 的算法变化如何约束素材 |
| 3 | 🌍 市场与投放数据 | `chartgrid` 趋势 + `stepper` 生命周期 + `chartgrid` 媒体类型 + `chartgrid` 地区 + `pmx` 发行矩阵 + **赛道军备竞赛** |
| 4 | 🎨 素材策略 | `tl` 时间线 + `chartgrid` 方向 + `filterbar` Hook 下钻 + `filterbar` 媒体下钻 + **专项拆解**(联动/版本) + `tplgrid` 模板库 |
| 5 | 🎴 素材画廊 | `gal` 可仿拍 8 条 + `fam/mgrid` 全量 + `details.sc` 脚本卡 20 张 |
| 6 | 🎭 创意体系 | `flow` 线性承接图 + `mmk` Markmap 交互脑图（`mmtree` 为旧静态版，可选） |
| 7 | 🔗 数据与创意的对应关系 | `tablewrap`（数据事实 → 解释的创意选择 → 商业含义） |
| 8 | 🧳 策略建议 | `aud` 三受众 |
| 附 | 🛂 数据口径与实体核验 + 🗺️ 数据边界与下一步 | `tablewrap` + `blockquote` |

### 必查数据维度

**必须拿到的（缺一项就补数，不要硬写）**：
- 窗口素材数 / 广告数 / 广告÷素材比
- 逐日或逐周趋势（8 个以上数据点）
- 媒体 TOP10-15 及占比
- 地区 TOP15 及占比 + 集中度（TOP1/TOP5/TOP10/其余）
- 素材类型分布（竖屏/横版/图片/网页/图标）
- 生命周期（首次投放时间、持续天数、是否放量）
- **赛道竞品 8–10 款的同口径素材数 + 广告数**（军备竞赛章节的命脉）
- 发行商产品矩阵（在投/已停投 + 停投时间）
- 创意方向 / Hook / CTA 占比（**标注 n= 样本量与「手工编码、误差 ±10pp」**）

**加分项**：时长分布、语言分布、是否含真人、ASR 台词、关键帧剪切点

### 特有章节

**赛道军备竞赛**（`chartgrid` + `tablewrap`）：
把 8–10 款同赛道产品的「素材数 / 广告数 / 广告÷素材比 / 媒体数」摆成一张表。
**这张表的价值在于回答「我的素材库是不是被对手甩开了」** —— 用同接口同口径实测，不要用二手数据。
比值解读：广告÷素材比越高 = 单条素材榨得越狠（饱和策略）；越低 = 铺量策略。

**专项拆解**（如联动 / 版本更新）：
用 `blockquote.warn` 给结论 + 两张 `tablewrap`（呈现方式 / 特征数值）+ `tl` 时间线。
**没有现成积木就组合**，不要为了套模板削掉这个章节。

## `short-drama` —— 出海短剧 App

**主题**：`base`（粉紫）　**骨架**：同 `game-strategy`；第 3 章换 `chartgrid`（语言/市场分布）、
第 5 章换按题材分族

### 与 `game-strategy` 的差异

| 项 | 游戏 | 短剧 |
|---|---|---|
| 第 3 章 | 地区分布 | **语言 / 市场分布**（短剧按语种池分，非按国家） |
| 第 3 章 | 赛道军备竞赛 | **剧目层还原**（从素材榜上升到作品榜） |
| 第 4 章 | 按 Hook 筛选 | **按语言筛选**（本地化策略） |
| 第 5 章 | 按创意方向分族 | 按**题材**分族（超自然 / 婚恋反转 / 逆袭 / 医疗伦理…） |
| 第 6 章 | 创意体系 | **竞品创意对比** + 变现模式（IAA/IAP）× 素材形态 |
| 素材量 | 千级 | **十万级** → 一律 A 档 |

### 必查数据维度

在 `game-strategy` 基础上**替换/增加**：
- **语种池分布**（每种语言的素材数 + 占比）
- **剧目 / 作品层聚合**：能从素材反查到剧名的，做作品榜
- **题材分类占比** + 与竞品的题材差异（如「奇幻题材占比 15% vs 竞品 4%」）
- **素材寿命**：最长存量素材天数（短剧类的常青素材很关键）
- **变现模式**：IAA / IAP / 混合

**关键提醒**：短剧类的「素材数」与「广告数」量级差异极大（广告÷素材比常达 40+），
**两个量纲不可互推**，表格里要分列。

## `app-tool` —— 工具 / 金融 / 生活服务 App

**主题**：`teal`　**骨架**：同 `game-strategy`；第 3 章换地区 × 媒体 `matrix`、
另加违规/合规专题（用 `blockquote` + `tablewrap` + `fam/mgrid` 组合）

### 与 `game-strategy` 的差异

| 项 | 游戏 | 工具/金融 App |
|---|---|---|
| 第 2 章 | 平台算法与推荐逻辑 | 可压缩为半章，或并入第 1 章 |
| 第 3 章 | 赛道军备竞赛 | **地区 × 媒体交叉矩阵** |
| 第 4 章 | 玩法表达 | **卖点表达**（工具类讲解决什么问题，不讲玩法） |
| 第 5 章 | — | **变现模式（IAA/IAP）× 素材形态** |
| 合规 | 一般不提 | **违规 / 合规专题**（金融类重点，务必查） |

### 必查数据维度

- 窗口素材数 / 广告数
- **地区 × 媒体交叉**（不同地区主投媒体差异）
- 素材类型（工具类竖屏占比通常极高）
- **合规/违规素材** —— 平台近 30 天窗口**只回传当期违规素材**，全历史违规要另开全量窗口单独问；
  报告里必须写清用的是哪个窗口，两者数字不能混用
- 变现话术覆盖率

**合规专题做法**（无专用积木，用组合）：
`signals` 式概述 `blockquote` + `tablewrap`（违规分几类 × 风险话术拆解）+ `fam/mgrid`（每类配封面素材）+ 热度排名表。

⚠️ **违规素材与创意方向必须分开统计** —— 违规素材常与合规头部素材**同母版**。
做「创意方向」聚类时**先剔除违规 ID**，否则等于把违规创意当可复制方向推荐。
并在口径里说明二者的同源关系。

## `competitor` —— 竞品对标专项

**用途**：用户已有自家报告，想看别人在打什么。

**骨架**（比 `game-strategy` 短，聚焦 4 章）：

1. 🧭 结论摘要 —— `sumgrid`，左栏直接给「差在哪」
2. 🌍 同口径横向对比 —— `chartgrid` + `tablewrap`（每款产品一行：素材数/广告数/比值/媒体数/地区数）
3. 🎨 创意打法差异 —— `chartgrid`（多产品 Hook 分布分组柱状）+ `tplgrid`（各家主力模板）
4. 🎭 借鉴与保持 —— `sumgrid` 的 `pos`/`neg` 双栏改成「✅ 应该保持的三条 / 🔁 应该借鉴的三条」，或直接用两张 `tablewrap`

**必查**：每款竞品**独立取数**，不要用自家报告里的二手数字。
**所有竞品必须同窗口、同接口、同口径** —— 这是这张表唯一的价值来源。

## `single-creative` —— 单素材深拆

**用途**：用户给一条素材（或 ID），要完整拆解。

**骨架**：单页，不用 nav 分章。顺序：

1. `hero` —— 素材本身 + 一句话结论
2. `gal` 大卡 —— 借鉴点 / 关键帧 / 为什么有效
3. `kfstrip` —— 真实抽帧（4–9 帧）
4. `details.sc` —— 10 字段脚本卡（开头三秒 / 中间吸引 / 转化逻辑 / 痛点 / 视角 / 音效 / 剪辑 / 分镜 / 受众 / 真人识别）
5. `details.rev` —— 逆向提示词（AI 变体骨架）
6. `aud` —— 改成「怎么仿拍 / 怎么变体 / 怎么避开」三栏

**注意**：
- 台词**只能用 ASR 转写出的原文**，取不到就写「不可得」
- 关键帧**必须真实抽取**，不能用封面重复充数
- 逆向提示词的台词也**只能用素材里真实出现过的句子**

## 通用结构铁律

不论哪个预设，都必须满足：

1. **总-分-总**：首屏 `sumgrid` 结论先行 → 主体分章 → `aud` 三受众动作 + 迭代脑图收尾
   （`flow` 线性承接图 → `mmk` Markmap 交互脑图；`mmk` 必须是最后一个内容块）
2. **一级导航 ≤7 章**（`game-strategy` 的 9 章属于上限，超出请合并）
3. **任何清单 ≤7 条**（KPI 卡、行列、脑图层）
4. **每个数据章节末尾必须有 `blockquote` 给结论** —— 不要裸表裸图
5. **不动不写**：正文出现数字的地方，都能追到接口字段或标注为样本编码
6. **不臆造**：取不到就写「不可得」「本轮未探测」，并在数据边界章节列明
